# Mailing Service

Курсовой проект на Django: сервис управления рассылками.

## Реализовано

- Регистрация пользователей.
- Подтверждение email.
- Вход и выход из системы.
- Восстановление пароля.
- Кастомная модель пользователя с авторизацией по email.
- Управление клиентами рассылки.
- Управление сообщениями.
- Управление рассылками.
- Динамическое обновление статуса рассылки.
- Ручной запуск рассылки.
- Сохранение попыток отправки.
- Статистика успешных и неуспешных попыток.
- Ограничение доступа по владельцу.
- Роль менеджера.
- Блокировка пользователей менеджером.
- Отключение рассылок менеджером.
- Серверное кеширование статистики.
- Клиентское кеширование через Cache-Control.

## Запуск

poetry install --no-root

poetry run python manage.py migrate

poetry run python manage.py create_manager_group

poetry run python manage.py runserver

## Проверки

poetry run python manage.py check

poetry run python manage.py makemigrations --check
